# YouTube JS 开销与风险检查

检查日期：2026-10-07。范围包括 `src/` 的七份功能与适配源码、`tools/` 构建及回归工具、`dist/request.min.js` 和 `dist/response.min.js`。检查依据是当前代码、固定发布路由、合成协议数据和本地回归；不是完整安全认证，也不是设备实测。

## 本次改动

- 发布包按请求/响应阶段保留实际使用的分支。旧 Onesie 初始化请求解密、离线 UMP 媒体改写和 Node 导出不进入发布包，原始研究源码和测试保留。媒体仍交由日志模块采样；Loon 初始化仍使用原有原生空视频规则。
- 删除日志模块从未调用的 `devFailure` 辅助函数及其恒为 null 的异常变量；导出仍明确使用 `exception: null`，不把没有捕获的异常伪称为已测量数据。
- 信息流解析在同一函数内复用字段边界，重复使用仍计入原有字段预算。取消全局缓存方案，因为它在本地对照中增加执行时间。频道过滤跳过名单未使用的标识类型，复用 UTF-8 解码器，减少临时数组和对象。
- 主入口解析的参数直接传入模块，避免再次解析参数和读取 Stash 页面开关。单独执行源码或处理器时仍能自行解析参数。
- 日志页面 POST 控制请求按大小写无关的 HTTP 头名称检查 Origin；存在冲突的多个来源头或明确的跨站请求时返回 403，先拒绝再读取/写入会话。无 Origin 的本地原生请求仍可使用。
- Onesie 配置每个原始密钥最多 1024 字节；缓存读取校验编码长度，写入不超过 8192 字符。异常配置原样放行并保留已有缓存。此限制是资源保护，不保证任意长度的密钥都能用于解密；实际解密另有严格长度与认证校验。

## 无用代码与重复代码

未使用的离线分支已经从手机包裁剪，但有协议回归价值，保留在可读源码中。日志脱敏、字段限额、异常放行与旧缓存迁移属于实际使用的保护逻辑，不能仅因一般播放时没有执行就删除。

多个独立模块含相似的日志辅助函数。这会增加源码和发布文本体积，但模块仍需独立回归、隔离作用域，不能直接按函数名合并。此次只删除确定无调用的函数和已核对的不可达顶层分支，没有自动删除所有“看似重复”的辅助函数。

## 已检查的安全边界

运行时源码中未发现 `eval`、动态函数构造、下载后执行文本、系统命令或文件系统读写调用；日志没有上传入口。构建和测试工具读取本地源码、生成本地文件、在 Node 沙盒执行仓库代码，均不进入手机运行时。

远程频道名单只在用户明确配置 URL 后由 Loon 独立任务下载；信息流处理不访问名单服务器。请求使用 HTTPS，未关闭 TLS 校验，禁止自动 Cookie 和重定向；有超时、64 KiB 文本、256 条目和 8 KiB 有效名单限制。内容按文本解析，拒绝网页和代码形式，不执行文本。实际数据仍要先由代理工具接收，JS 的大小限制不能阻止底层已经发生的下载。

字幕功能只改写匹配的 YouTube 字幕 GET 请求，不向第三方翻译服务发送文本；不修改签名明确覆盖的 `tlang`。API 清理保留未知字段与媒体内容，结构不支持、截断或超限时放行原响应。

日志写入前按安全头和字段结构脱敏，移除已识别的令牌、Cookie、密钥、身份内容及媒体正文。未知字符串不保存原文。页面有 HTML 转义、CSP 和禁止嵌入策略；控制来源检查用于减少网页误触发，不是密码认证。

## 仍需注意的风险

1. **本地密钥缓存含敏感信息。** `ytads.onesie.youtube.v1` 为有效期内的配置保存密钥，Base64 是编码，不是加密。有效期来自受限配置，最多七天，读取过期配置时删除；密钥不进入日志导出。持久化存储保护依赖代理工具和设备，不能承诺设备或存储被读取后仍保密。
2. **完整采样有性能成本。** full 模式、画质研究及正文重写可能让代理工具等待正文、占用内存。关闭日志会停用媒体采样，但普通 API 去广告仍需读取正文。JS 解析限额无法撤销规则已经触发的底层缓冲。
3. **私有协议和客户端行为会变化。** 初始化空视频、QUIC 回退和响应清理可能在未验证的客户端触发重试或播放异常。没有本次证据证明可消除首帧黑屏、推荐流等待或 Apple TV 无网络。
4. **配置来源仍需可信。** 用户选择的远程名单服务器会看到独立下载请求；远程名单缓存保存 URL 与名单，仅供过滤使用，不写入日志。主插件引用 main 分支跟随更新，安装其他来源的覆写或 JS 会改变本次审查边界。
