# 搜索结果网站屏蔽（Loon）

版本：`1.0.4`。作者：可莉唯一的狗、ChatGPT。

在 Loon 中手动配置黑名单或远程订阅，隐藏搜索页面中目标域名匹配的结果条目，并保留其他普通结果。主要支持 Google，同时适配 Bing、百度的已识别网页结果。不限浏览器，不按浏览器名称或 User-Agent 过滤请求；无需制作或安装浏览器扩展。插件没有网站访问拒绝规则：验收标准是搜索条目消失，而非链接无法访问。

## 安装与设置

在 Loon 中添加以下远程插件地址：

```text
https://raw.githubusercontent.com/teaoea/shell/main/plugins/SearchFilter/SearchFilter.plugin
```

1. 添加并启用插件，开启 Loon 的脚本和 HTTPS MitM，安装并信任 Loon 证书。
2. 运行插件里的“添加黑名单”手动脚本入口，点击通知打开本地名单网页；也可在浏览器直接访问 `http://search-filter-list.invalid/`。
3. 在网页勾选 Google、Bing、百度，点击“保存设置”。这组选项控制整份本地名单及订阅；默认全部勾选，全部取消则三个引擎均不处理。
4. 点击输入区上方的 `domain-keyword` 或 `domain-suffix` 快捷按钮，自动插入类型、冒号和空格；填写内容后点击“添加并保存”。可粘贴多行规则，每行一项。列表内提供编辑和删除，保存直接写入本机 Loon。
5. 展开“搜索排除与远程订阅”，可配置默认关闭的额外搜索排除、订阅地址和更新订阅，修改配置后先保存设置。
6. 重新发起搜索，命中名单的已识别条目隐藏，其他结果保留。

结果屏蔽是插件的默认功能，不设总开关。Loon 的参数区只保留默认关闭的“日志工具”；黑名单输入框、三个引擎开关、额外排除和订阅 URL 均已移到网页。关闭整个插件后重新搜索可恢复原始结果。

更新时刷新插件和脚本缓存。**旧版输入框中的名单和搜索设置不会自动迁移**：新版不再向脚本传入这些参数，需要在网页重新添加明确类型的规则并保存设置。名单、引擎选择和订阅地址均仅保存在本机，不跨设备同步。

Loon 原生参数只提供文本、单选和开关，插件不能改造原生键盘工具栏；本地网页的输入区提供两个快捷按钮，并按浏览器可用的可视区域调整位置。[Loon 插件参数](https://nsloon.app/docs/Plugin/)

“添加黑名单”是 Generic 手动脚本入口，点击后发出网页入口通知；**还需点击通知打开网页，不能由脚本直接自动跳转浏览器**。通知显示受系统和 Loon 权限影响。建议给本地网页添加书签。[Loon 通知 API](https://nsloon.app/docs/Script/script_api/)

## 名单规则

本地网页与远程订阅使用相同的显式格式，冒号后至少一个半角空格，每行一条，不再支持通配符：

```text
domain-keyword: csdn
domain-suffix: example.com
domain-suffix: blog.example.org
```

| 格式 | 匹配方式 | 范围 |
| --- | --- | --- |
| `domain-keyword: csdn` | 倒数第二个域名标签完全相等 | `csdn.com`、`csdn.net`、`blog.csdn.net`；保留 `notcsdn.net`、`csdn.example.org` |
| `domain-suffix: csdn.com` | 指定域名本身及所有子域名 | `csdn.com`、`blog.csdn.com`、`a.blog.csdn.com`；保留 `csdn.net`、`notcsdn.com`、`csdn.com.evil.net` |
| `domain-suffix: blog.example.org` | 指定子域名及其下层 | 保留父域名 `example.org` 和其他同级子域名 |

`domain-keyword` 的关键词是一个完整域名标签，不是任意子串，也不按结果标题或正文匹配。倒数第二个标签规则不提供 Public Suffix List 注册域名推断；例如 `blog.csdn.net` 的标签是 `csdn`，`csdn.com.cn` 的标签是 `com`。

推荐使用标准拼写 `domain-keyword`；兼容 `domian-keyword`、`domain-keywrod`、`domian-keywrod` 的已声明类型，保存后统一显示标准拼写。单独填写 `csdn`、`csdn.com`、冒号后无空格或用制表符代替空格、带 `*`、完整 URL、路径、端口、IP、用户名密码均无效，不会按裸字符串推断类型。网页遇到无效规则会提示并保留已保存名单。中文域名请填写 Punycode。

空行、`#` 或 `//` 开头的整行注释忽略，大小写统一，重复规则合并。本地最多 100 条规则，批量提交文本最多 8192 字符；订阅最多 100 条，两者按任一命中即隐藏合并。只想屏蔽某个域名后缀时，使用对应的 `domain-suffix`，并确保其他本地或订阅规则没有更宽的关键词匹配；窄规则不覆盖宽规则。

## 远程订阅

在本地名单网页展开“搜索排除与远程订阅”，填写公开 HTTPS 文本直链，先点击“保存设置”，再点击“更新订阅”。输入留空并保存会立即停用订阅。页面显示有效缓存条目数及更新时间。

订阅正文使用上节相同的每行格式。兼容旧订阅中的显式 `[key: csdn]` 和 `[url: csdn.com]`，冒号后同样必须有空格；**旧的通配符规则不再支持**，例如 `[url: *.csdn.com]` 需改为 `domain-suffix: csdn.com`。旧缓存中的通配符条目会被过滤器忽略。

插件启用时每小时整点尝试更新，系统休眠、锁屏或调度可能延迟。搜索仅读取本地缓存，不等待下载。下载非 200、正文超过 256 KiB、存在无效行、超过 100 条或保存失败，均保留上次有效缓存；空文件或仅注释表示清空订阅。

修改订阅地址后，旧地址的缓存立即退出匹配，直到新地址成功更新；更新失败的旧有效缓存不会自动过期。本地条目与订阅合并，删除本地条目不会删除订阅规则。订阅请求由 Loon 独立发出，不复制浏览器 Cookie、Authorization 或搜索词；使用公开、无凭据的 HTTPS 文本地址，每台设备独立缓存。

## 开发日志与隐私

日志工具默认关闭。开启后，首次被脚本检测到时自动开始记录并弹出日志页入口通知；点击通知打开本地日志页，不需要另点“开始记录”。后续搜索不会逐次重复提醒。也可手动运行“搜索屏蔽开发日志”，或在浏览器访问：

```text
http://search-filter-logs.invalid/
```

Loon 没有插件开关变化的即时回调。插件在首次匹配的请求、响应、订阅脚本执行时检测开关；没有流量时，每分钟的本地状态检查也会检测，只读取本地存储，不发起网络请求。设备休眠、锁屏和系统调度可能延迟检查，不能保证保存开关后立即触发。两次脚本执行之间快速关闭再开启，可能无法观察到关闭状态。通知显示取决于系统和 Loon 通知权限；Loon 官方接口的 `openUrl` 需要点击通知才能打开页面，无法从后台强制自动打开浏览器。[Loon 通知 API](https://nsloon.app/docs/Script/script_api/)

页面提供一个随状态切换的“开始记录／暂停记录”按钮，以及刷新日志、导出日志、清空并暂停。所有操作均在当前页面完成，不重载或跳转；导出直接下载 `search-filter-development.log`，可在浏览器下载列表查看。暂停和清空后保持暂停，后续搜索及状态检查不会擅自恢复；可在本页点击“开始记录”恢复。开关关闭状态被检测到后，再开启会自动开始新一轮记录与入口提醒。关闭开关后停止写入，旧日志保留，仍可查看和导出。没有日志时导出按钮禁用。页面按设备时区显示时间，导出保留 UTC 时间，每条记录保留其原版本。

日志最多保留最近 300 条，自动淘汰更早条目。只存储本机 Loon 日志空间，与订阅缓存分开，不自动上传。写入和导出均通过字段白名单，允许字段只有时间、插件版本、请求发出／响应返回／订阅更新阶段、搜索引擎、已登记的固定搜索主机、`/search` 或 `/s` 固定入口、HTTP 状态、有效规则数量、Google 初始结果识别／移除／目标不明数量和固定处理结果代码。

**不会记录搜索词、查询参数或 URL 片段、完整 URL、结果目标域名、标题摘要或页面正文、任何请求／响应头、Cookie、Authorization、账号、设备标识、IP、浏览器标识、黑名单内容、订阅 URL 或网络错误原文。** 时间和使用的搜索引擎属于仍保留的诊断元数据；分享前可自行删去时间。插件正常功能所需的黑名单和订阅来源仍由设置／独立订阅缓存保存，不包含在开发日志导出中。

处理结果可区分没有规则、非完整 HTML、响应超限、CSP 禁止脚本、已移除初始结果和已注入脚本。Google 响应日志增加 `recognized`（识别到的初始单结果容器数）、`removed`（本次实际从 HTML 删除的容器数）、`unresolved`（已识别容器中无法明确目标域名的数量）。数量不包含浏览器后续加载的动态结果；移除为零不证明没有黑名单条目，可能是初始响应没有结果或布局尚未识别。“已注入过滤脚本”仅表示 Loon 修改了页面，**不证明浏览器已隐藏条目**；日志不采集浏览器 DOM、页面标题或被隐藏网站名单。零条日志仅说明未采集到，不能证明没有发出连接。请求日志的“请求发出”指请求进入发送前脚本阶段，不等于收到服务器响应。

开启日志工具时，搜索页面右下角还显示“搜索屏蔽 v1.0.4”状态按钮：

- “脚本尚未执行”：Loon 插入了提示，但未观察到页面脚本执行；不能据此判断是禁用脚本、页面策略还是加载过程造成。
- “已运行 · 隐藏 N”：浏览器脚本已扫描；点击可查看规则数、标题数、识别数、目标不明数和当前隐藏数。
- “页面处理异常”：页面过滤发生异常，诊断不导出错误原文。

该状态按钮只在日志开启时显示，不包含搜索词、黑名单、目标域名或页面正文。按钮内可直接下载 `search-filter-browser.log`，内容是固定版本／时间／阶段／引擎／状态和计数；没有 Cookie、URL、令牌、设备信息，不发出 fetch、Beacon 或其他网络请求，不写入 Loon 日志空间。它与 Loon 的 `search-filter-development.log` 是不同采集阶段，排查时可分别提供。浏览器当前隐藏数不含 Loon 已从初始 HTML 删除的条目，两个计数不能直接相加。默认关闭日志时不显示页面提示、不生成诊断文件。若 Google 替换或重载页面，状态随当前页面重新统计。

日志页面由 Loon 本地生成，不连接外部服务器；控制操作要求本地来源与随机令牌。不要把本地控制令牌作为排查材料分享。存储失败不影响搜索过滤；并发脚本更新日志可能丢失部分事件或重复入口通知，日志不保证完整流量覆盖。

## 支持范围

| 搜索引擎 | 明确覆盖的主机与入口 | 状态 |
| --- | --- | --- |
| Google | `google.com`、`google.com.hk`、`google.com.tw`、`google.co.jp`、`google.co.uk`，以及各自的 `www`；`/search?q=…` | 主要适配：`#search`／`#rso`／`#main` 下带 `h3` 或 `role="heading" aria-level="3"` 的单结果 `.g`／`.MjjYud`／`.tF2Cxc`／`.vt6azd`／`.Ww4FFb` 等容器；初始 HTML 移除加动态隐藏 |
| Bing | `bing.com`、`www.bing.com`、`cn.bing.com`；`/search?q=…` | 适配 `li.b_algo` 普通结果和已识别的编码跳转链接 |
| 百度 | `baidu.com`、`www.baidu.com`、`m.baidu.com`；`/s?wd=…` 或 `/s?word=…` | 适配 `.result`／`.c-container`；依据真实链接、明确的目标 URL 或显示的完整域名 |

只处理 HTTPS GET。Google 图片、新闻等 `tbm` 页面和除 `udm=14` 外的特殊 `udm` 页面放行；百度仅处理上述普通入口，已带其他垂直搜索 `tn` 标记时放行。POST、搜索建议、翻译、登录、其他主机、其他搜索引擎不处理。百度移动端 `/from=…/s` 等嵌套路径暂未覆盖。

iOS、iPadOS、macOS 共用同一插件。不限制 Safari、Chrome、Firefox、Edge 或其他浏览器，只要搜索请求经过 Loon 并成功解密，就会进入相同处理逻辑；Google 初始 HTML 移除只要求结果布局和目标域名可识别；动态隐藏和 Bing／百度页面过滤还需要浏览器支持并允许 JavaScript、页面 CSP 允许注入脚本。不能据此声称已在每种浏览器上实测。

浏览器内置代理、独立 VPN、隐私转发等路径如果实际绕过 Loon，插件无法处理该流量；禁用页面脚本时，Google 已识别的初始结果仍可移除，动态结果及 Bing／百度注入过滤无法执行。macOS 还受 Loon 自身安装条件约束：[Loon App Store](https://apps.apple.com/us/app/loon/id1373567447?platform=mac) 当前列出的 Mac 要求是 macOS 11 或更高、Apple M1 或更新芯片；不承诺 Intel Mac 可用。三套系统均尚未完成实机验证。

## 效果与排查

插件通过 Loon 修改搜索 HTML，先从 Google 初始 HTML 中移除命中的已识别单结果容器，再在允许时加入本地脚本处理动态结果。Bing／百度沿用页面脚本隐藏已识别结果容器，不改写正常结果的链接、标题或摘要。容器含多个标题、目标域名不明、布局不认识时保留，避免误删邻近结果。只提到被屏蔽网站的正常页面会保留。脚本监听动态结果；同一容器被复用为正常结果时恢复原来的显示属性。

百度不透明的 `/link?url=…` 不能直接解出域名；只有明确目标 URL 或显示完整域名才过滤，不根据“CSDN 官方网站”这样的名称猜测。广告、AI 回答、知识卡片、图片／视频结果以及未知布局目前不保证覆盖。

页面过滤仅处理 HTTP 200、`text/html`、含闭合 `body` 且正文不超过 4 MiB 的响应。保留原页面的内容安全策略（CSP），可复用既有脚本 nonce；如果策略不允许注入脚本且没有可用 nonce，Google 已完成的初始结果移除仍返回浏览器，动态隐藏停止；未发生移除或其他引擎则放行。不会删除 CSP 来强行执行脚本。严格策略、浏览器禁用脚本、动态片段无初始注入等情况可能导致页面过滤未运行。Google 初始已识别条目在返回浏览器前移除；动态结果依赖浏览器脚本隐藏，仍可能短暂显示。初始 HTML 解析跳过脚本、样式、注释和惰性模板，遇到不完整或混合容器保留；最多解析 60000 个标签、256 层嵌套，超限保持初始 HTML。

插件自身不记录搜索词。默认关闭的日志工具仅保存上节列出的诊断元数据。只有配置订阅时才请求远程名单，并在独立缓存保存规则、来源 URL 和更新时间。页面中的规则可被当前搜索页面脚本读取；开启额外条件后，精确域名还会随查询发送给当前搜索引擎。

可选的“额外追加搜索排除条件”只对域名后缀规则追加 `-site:`，帮助搜索引擎直接返回更多未屏蔽结果；域名关键词始终由页面过滤。已存在的相同排除条件不重复追加，改写 URL 超过 16384 字符放行。Google 官方支持网站排除；Bing 文档说明只使用前 10 个搜索词，长名单可能失效；百度执行 `-site:` 的效果待实测。这些限制不替代页面条目过滤。

验收时保持额外条件关闭，选一个能同时搜到目标域名和正常网站的关键词：先保存关闭插件时的结果，再开启插件、网页添加 `domain-keyword: csdn` 并重新搜索。目标条目应消失，邻近正常网站应保留；再翻页或滚动加载检查动态条目。也要测试 `notcsdn.com` 不误删。不能仅凭请求成功、HTTP 200 或脚本命中判断过滤成功。

如果条目未消失，检查网页名单、引擎复选框及保存状态、Loon 脚本缓存、实际主机与路径、MitM 证书是否信任、浏览器流量是否绕过 Loon、页面 CSP 和结果布局。HTTP/3／QUIC 连接若未进入可解密脚本链路，需要在 Loon 中针对实际搜索主机配置回退或使用可处理的连接；本插件没有自动拒绝 QUIC 的规则。缓存页面需要重新发起搜索。

关闭插件或取消对应引擎后重新加载页面，即可恢复结果；已打开页面中的过滤脚本不会被远程撤回。如果曾开启额外条件，已进入搜索框、地址栏、历史或分页链接的旧条件需要手动删除后重新搜索。

## 验证状态与来源

本地测试覆盖 Google、Bing、百度请求改写，显式域名关键词／域名后缀匹配和通配符拒绝，跳转链接识别，邻近正常结果保留，动态容器更新和恢复，CSP 放行、订阅解析与缓存、订阅失败保留、URL 切换隔离、配置主机边界、日志隐私白名单和本地控制、原页状态 JSON、清空后的令牌更新、Google 原始 HTML 移除、禁止页面脚本时移除仍生效及恶意／不完整模板保留。

2026-10-08 在真实 Google 页面观察到 `/goto?url=…` 不透明链接，条目引用仍显示 `https://blog.csdn.net` 等完整域名。已将该结构提炼为使用虚构标题和跳转令牌的最小回归样例，并在实际浏览器中渲染过滤后样例：`blog.csdn.net`、`bbs.csdn.net` 隐藏，`developer.mozilla.org`、`notcsdn.net` 保留。其余 DOM 单元测试使用模拟容器。v1.0.2 在实际浏览器验证了手机宽度布局、开始／暂停／清空／刷新原页更新、日志文件下载不跳转；在 CSP 禁止全部页面脚本的样例中，两个 csdn.net 条目已从 HTML 移除，两个正常条目仍可见。以上使用本机临时服务和模拟 Loon API，不是实际 Loon 客户端执行。

v1.0.3 在实际浏览器验证手机标题结构的延迟加载和整段 body 替换：关键词 `csdn` 隐藏两个 `.net`／`.com` 结果并保留正常邻居；`*.csdn.com` 只隐藏 `.com`；CSP 禁止全部脚本时初始手机结果也按相同边界删除。页面执行状态能够显示识别数与当前隐藏数，测试页不使用用户查询。手机结构依据下列上游适配定义构造最小样例，并非抓取用户设备页面。

这些验证不等同于用户设备上的 Loon MitM 与动态 Google 页面端到端测试，三套系统、全部浏览器及 Bing／百度实机效果仍未确认；GitHub 发布与下载检查也不等于设备已加载或过滤效果已确认。

v1.0.4 的模拟 Loon API 测试覆盖显式多行名单在三种引擎的匹配、裸规则拒绝、开启自动记录、旧版暂停状态迁移、后续执行不重复通知、暂停及清空保留、关闭再开启、默认关闭不写日志、通知失败不影响过滤、导出排除控制状态。本机浏览器已验证 390 像素手机布局、类型快捷输入、原页添加／编辑／删除、引擎复选框保存和模拟订阅更新。该网页测试使用临时本机服务与模拟 Loon API，未在用户设备确认通知展示、输入法弹出后的布局或 Cron 调度。
